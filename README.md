# ENAMOR#ARTE — Joyería Artesanal de Autor

Sitio web oficial y catálogo interactivo de **ENAMOR#ARTE**, taller de joyería artesanal de autor por **Laura** (Mendoza, Argentina).

## 🌸 Características
- **Diseño editorial de alta gama**: Estética cuidada con paleta beige, bordo y rosas, inspirada en joyería fina contemporánea.
- **Colección Serenidad**: Vitrina de piezas únicas forjadas a mano con flores silvestres, resina cristal, caracolas y elementos botánicos.
- **Catálogo de Nuevos Ingresos**: Fichas de producto interactivas con pedidos directos vía WhatsApp.
- **Trabajos por Encargo & Eventos**: Sección para souvenirs personalizados de bodas, 15 años y eventos especiales.
- **Optimización & Rendimiento**: Imágenes optimizadas con alta fidelidad, carga diferida (`loading="lazy"`), y adaptabilidad 100% responsive en todas las pantallas.

## 🚀 Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Vanilla CSS con Custom Properties y Media Queries)
- JavaScript Vanilla
- Integración con WhatsApp oficial
